# Action Regulator

Action Regulator is a Minecraft mod that allows you to block actions in the game. 
It offers a simple and intuitive interface to configure which actions you want to block.

## Features
Currently, Action Regulator offers the following modules:
- **Block Breaking**: Prevent players from breaking blocks. 
  - Specify one, multiple, or all blocks to be blocked.
  - Specify one, multiple, or all hand items for which the block breaking will be blocked.
  - Specify the dimension in which the block breaking will be blocked.
  - Specify how the player should be notified when they attempt to break a block that is blocked.
